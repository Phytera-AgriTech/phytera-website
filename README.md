# Phytera AgriTech Website

Official website for **Phytera AgriTech**.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages

This site is designed to work as a static GitHub Pages website from the repository root.

Repository: https://github.com/Phytera-AgriTech/phytera-website

## Structure

- `index.html` — main webpage
- `styles.css` — responsive styling and visual system
- `script.js` — navigation and interaction behavior
- `assets/` — Phytera visual assets
